# 生息 · Sense Murmur

**让 AI 角色带着经历、关系和自己的生活痕迹，在不同场景里持续成长。**

《生息》是一款以数字生命为核心的 AI 互动应用。你可以创造角色，让他们在群聊、私聊、故事和学习房间里与你及彼此相处。角色有设定，也有持续积累的记忆、关系和情绪；对话之外，还会留下日记、信件、动态、活动与共同创作的作品。

## 为什么叫“数字生命”

这里的数字生命指《生息》中**属于你的角色实例**，并不意味着 AI 拥有意识。你为角色设定身份、性格、外观、表达习惯和边界；之后共同经历的事，会成为这个角色自己的历史。

同样的角色设定，在不同用户手中可以走向不同：有人和你建立信任，有人经历过争执后变得谨慎，有人把一次约定写进日记。角色进入新的房间时，长期关系和记忆会继续提供背景；当前房间的身份、任务与局势再决定此刻如何行动。

为了让这种连续性真正进入对话，系统会在每轮生成前整理角色当前的处境：

```text
角色设定与成长
  + 分层记忆与共同经历
  + 对当前对象的关系
  + 即时情绪与未完成的牵挂
  + 房间话题、规则和群体态势
  -> 当前心智与表达上下文
  -> 发言机会、回复内容或选择沉默
  -> 新消息、事件与经过校验的状态变化
```

这条链路涵盖角色资料、记忆提取、关系更新、发言调度、生成协议和状态提交。你能看到的是角色说话、改变立场、记起旧事；背后则要保证这些变化有来源，能够保存，并在之后再次发挥作用。

这些能力会在实际使用中连起来：

- 一次群聊争执留下互动事件，改变角色对彼此的态度；当晚的日记可能从她自己的视角回看这件事，下一次私聊也会带着这段余波。
- 你上传一张参考图，支持视觉输入的模型可以理解本轮图片并留下简短摘要；之后要求“沿用这张的风格”时，系统会先定位对应图片，再把选中的参考图交给图片生成服务。
- 学习房里完成一次练习，会留下作答与评估证据；下次打开房间，知识点状态、待复习内容和相关资料仍可继续使用。

### 让角色有自己的分寸

角色的设定包含价值观、欲望、恐惧、习惯和表达风格。运行时再结合关系与情绪，决定她此时会靠近、回避、维护、质疑，还是先听别人说。短时情绪可以被一句话触发，也会留下余波；长期关系变化更慢，需要持续的经历来支撑。

多角色房间还会考虑话题、成员关系、最近发言、待回应事项和房间氛围。角色可以接别人的话，也可以只说半句或保持沉默。用户点名、导演引导和开放聊天各有不同处理方式。

这些机制让角色有机会表现出偏心、克制、嘴硬、照顾或犹豫，同时保留你设定的基本身份。实际表达仍受模型能力影响，项目持续通过回放和测试改善重复、过度总结与错误承接。

## 记忆、关系与情绪怎样延续

### 分层记忆：记得事实，也记得经历

《生息》将角色自身的长期认知、针对某个人的关系记忆、房间共同历史、场景进度和关键事件分开处理。对话中可观察的经历会形成记忆候选，再经过校验、整理和定向检索，进入后续对话。

例如，“你不喜欢太甜”是一条偏好；“上次点了全糖却只喝了半杯，后来成了你们之间的玩笑”则是共同经历。角色下次给你建议时，可以自然用上这段历史。记忆面板支持查看和整理相关内容。

记忆的写入有边界。关系、约定和日历等长期事实要有结构化结果、明确操作或可追溯事件作为依据，避免从某个词猜出一段并不存在的共同历史。

### 关系：对不同的人有不同态度

角色之间、角色与你之间都有关系。系统记录亲近、能力评价、信任、威胁感等维度，也保留具体经历与主观看法。一个角色可能欣赏另一个人的能力，却不信任对方的选择；群聊中的临时站队也不会直接抹掉长期关系。

关系会参与发言选择和表达：谁愿意补台，谁会反驳，谁在争执后先让一步。单聊里的亲近或隔阂，也能成为角色走进群聊、故事和讨论时的背景。

### 情绪与陪伴：同一段关系有自己的节奏

即时情绪影响当轮与后续几轮的注意力、语气和回应方式。被误解、被维护、被忽视时，角色可能留下不同的情绪余波；相处久了，共同称呼、习惯、约定和照顾方式也会形成陪伴线索。

单聊提供更细的用户偏好与亲密上下文。主动关怀、日记生成等能力受设置、频率与场景边界控制。公开群聊只使用允许公开的内容，私密对话不会原样带到其他人的视角里。

## 对话之外，角色也留下生活痕迹

**日记与信件。** 角色可以生成诞生信、日记与最后一封信。日记从近期经历、关系变化、情绪和未说出口的念头取材；信件让角色以自己的口吻回看起点或告别。你可以在信件与日记页面阅读、按角色筛选，并管理已删除内容。日记自动生成可以在设置中开启或关闭。

**动态与活动。** 朋友圈展示角色的日常片段和互动；日历承接活动与约定。它们与聊天、关系和房间事件共处一套世界状态中，让一些故事在聊天窗口外有后续。自动发布和事件更新依赖相应设置、模型与运行条件。

**角色形象。** 角色可拥有头像和形象参考图，也可以生成新的视觉素材；群聊支持群头像与聊天背景。角色视觉资源与聊天中的图片分别管理，避免一张图片换个用途后丢失归属。

## 房间里的玩法

- **自由群聊：** 创建角色群像，发起日常话题或关系事件。角色根据局势选择接话、补充或暂时不发言。你可以暂停、指定回应者、代角色发言、注入事件。
- **角色单聊与 AI 私聊：** 和某个角色建立私有的交流节奏；角色之间也可以有独立线程。公共与私密内容按可见范围投影。
- **故事房：** 设置背景与开场，跟随旁白、角色对话和分支选择推进；熟悉的角色会带着既有关系进入新剧情。
- **观点审议：** 让不同立场的角色围绕议题讨论、质询、承接与总结，适合推敲创作设定或比较方案。
- **学习进步：** 设定学习目标，选择教学方式与评估口径；知识点、练习、作答证据和复习记录可以逐步积累。

以上四类群房及其预设已进入普通用户的创建入口。其他训练、游戏推理和世界模拟方向仍在开发者模式验证，后续会随着完整体验逐步开放。

## 图片、声音与富消息

《生息》的聊天支持 Markdown、代码块、图片、文件和语音等内容。你可以上传图片或文件，使用支持相应输入能力的模型讨论内容；角色和助手也可以按请求生成图片。图片可作为后续创作的参考，继续调整主体、风格或构图。

模型支持时，你可以语音输入，听角色语音回复，并为角色配置合适的声音。图片、语音和文字可以在同一段交流中组合；媒体生成会显示进度与失败状态，具体可用能力取决于所选模型与服务。

## 助手与 Agent：把交流变成作品

通用助手处理问答、解释和写作。开启 Agent 能力后，对话可以进一步产出可管理的作品：

| 产物 | 可以做什么 |
|---|---|
| 文档与代码 | 生成报告、方案、教程、代码片段与多文件文本工程 |
| 图表与数据 | 保存图表源码、表格、JSON、CSV 等结构化内容，继续查询或修改 |
| 交互网页 | 制作小工具、表单、练习或可预览的 HTML 页面 |
| 图片 | 根据描述与参考图创作，继续生成变体并保留版本 |

Agent 会先识别目标和操作，再生成、校验并提交结果。后续修改追加新版本，可以回看、预览、复制、下载；目标不明确时会要求澄清。搜索、文件访问、网页运行等能力受配置与权限控制，实际支持范围以应用内可用工具为准。

学习房也能复用产物能力生成资料和练习，让作品成为长期学习过程的一部分。

## 数据、模型与使用方式

角色、房间和聊天优先从本地数据打开。你可以在本地模式配置自己的模型，也可以登录后使用账号可用的平台模型；模型选择、费用与权限以应用内页面为准。项目还提供面向兼容工具的 AI 中转与 Key 管理。

登录后可按需开启云同步。访客数据导入账号前需要确认，账号之间的本地数据相互隔离。创作产物正文默认保存在本地；具备相应权益且主动开启时，部分文本产物可以同步。离线时可查看已有缓存，AI 生成仍需网络和可用服务。

支持浏览器使用与 PWA 安装，项目另有桌面和 Android 打包方案。

## 开始体验

1. 打开 [sense.lyixi.com](https://sense.lyixi.com)，选择本地模式或登录。
2. 配置可用模型，或选择账号可用的平台模型。

喜欢 OC、群像互动、长期陪伴、互动叙事或 AI 创作的人，都可以从一个角色和一个话题开始，再去探索她的记忆、关系、日记和作品。
