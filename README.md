# 生息 · Sense Murmur

《生息》是一款围绕多角色聊天、长期陪伴和互动故事展开的 AI 应用。

创建自己喜欢的角色，把他们放进同一个房间，聊日常、交换想法，也一起走进故事。相处中的记忆、关系和小约定，会成为下一次对话的背景。

**[在线体验](https://sense.lyixi.com)** · QQ 群：571886312 · [English](./README.en.md)

## 可以怎么玩

### 走进一个热闹的小群

挑几个角色，抛出一个话题。有人讲道理，有人开玩笑，有人和你意见不同。角色可以互相接话，也可以围绕某个细节聊下去。

你可以参与其中，也可以暂时旁观。想改变方向时，可以指定角色回应、代角色说一句话，或给房间加入一个新事件；需要休息时，随时暂停。

### 和某个角色慢慢熟起来

想安静一点，可以和一个角色单独聊天。

为角色设定背景、性格、表达习惯和边界，再通过相处逐渐积累共同经历。你们的偏好、旧事和关系线索可以保存在角色记忆中，也能查看和整理。熟悉的角色进入其他房间时，会继续使用已有的关系与记忆背景。

你们在群里争论过什么，后来又如何和好，都有机会影响之后的语气和态度。这种连续性是《生息》持续打磨的重点。

公共群聊、你与角色的单聊、角色之间的私密线程各有可见范围，私密内容的公开回流受到限制。

### 带熟悉的人进入故事

选择故事房，设定开场、背景和方向，和角色一起面对新的处境。

通过旁白、角色对话和分支选择推进剧情。你可以阅读故事，也可以参与演出；已有的角色关系会为同一个选择带来不同的理解和反应。

想试另一种走向，可以编辑消息、重新生成回复或切换对话分支。

喜欢 OC、群像、互动小说或角色扮演，可以从一个简单场景开始：雨夜重逢、校园社团、一次临时旅行，看看这群人会把故事带到哪里。

### 把一件事讨论明白

在观点审议中，让不同立场的角色围绕一个问题展开讨论、质询和总结。适合推敲创作设定、比较方案，或从几个角度重新理解自己的想法。

### 围绕一个目标慢慢学

在学习进步房间里，选一位角色陪你学习，设定总目标，逐步梳理知识点、生成资料和练习。学习记录为后续安排提供参考，也方便回看学过什么、哪些地方还需要练习。

可以从读懂一本书、理解一个技术概念开始，选择轻松陪练或严肃学习，并设置练习的评估方式。

## 开始体验

1. 打开 [sense.lyixi.com](https://sense.lyixi.com)，选择本地模式或登录。
2. 在模型设置中配置可用模型，或选择账号可用的平台模型。
3. 从预设角色开始，也可以创建自己的角色。
4. 创建房间，发出第一条消息。

喜欢安静陪伴，就先和一个角色单聊；喜欢看群像互动，就把几个性格不同的角色放进同一个房间。

## 还能做什么

### 通用助手与创作产物

需要问问题、写东西或整理思路时，可以打开通用助手。

按需开启 Agent 能力后，可以把结果保存成文档、代码、图表、HTML 小工具或结构化文本，再继续修改、查看版本、预览和下载。适合把一次讨论整理成方案，或把一个点子做成可试用的小网页。

### 图片与语音

对话支持 Markdown、代码和媒体内容；配置相应模型与服务后，还可以生成图片、制作角色形象、使用语音输入和语音播放。

### 动态与日历

通过动态回看角色的日常片段，通过日历查看活动与约定。自动发布和活动更新取决于相关设置及运行条件。

### 自选模型

可以配置自己的模型服务，也可以使用平台提供的模型。平台还提供 AI 中转与 Key 管理，便于把模型调用用于其他兼容工具；可用模型、价格与权限以站内页面为准。

## 在自己的设备上继续

《生息》优先读取本地保存的角色、房间和聊天。支持 PWA，可在兼容浏览器中安装到桌面或手机主屏幕；项目也提供桌面端和 Android 打包方案。

登录后可按需开启云同步，在设备之间继续使用。将访客数据导入账号前，应用会先征求确认。

创作产物正文默认保存在本地，部分文本产物可在账号具备权限且主动开启后同步。换设备前，请确认同步状态并导出重要作品。

离线时可查看已缓存的内容，AI 回复、图片和语音生成仍需要网络与相应服务。

## 项目近况

《生息》仍在持续开发，近期重点是角色差异、记忆与关系的连续性，以及故事与学习体验。

其他训练、游戏推理、世界模拟等方向仍在实验中，部分仅在开发者模式开放。角色卡分享与创作者生态是后续规划。

多角色对话和长期记忆会受到模型及上下文影响，目前仍会出现重复表达、记忆遗漏和错误承接。欢迎在 QQ 群反馈具体场景和复现步骤，分享时请先去除私人对话、密钥等敏感信息。

## 参与开发

前端使用 React、TypeScript、MUI 和 Vite。架构、环境配置与验证命令见 [完整项目的开发者文档](https://github.com/lyixi/Pneumata#readme)。

只运行此客户端时：

```bash
npm install
npm run dev
```

本地模式需配置可用模型；账号、平台模型与云同步等能力需要后端服务。完整项目通过 npm workspaces 管理前后端。
